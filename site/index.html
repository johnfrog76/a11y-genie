A11y Genie

A11y Genie scans web pages for accessibility problems and tells you what to fix first.

An accessibility scanner for agents and people. It finds some problems, never all of them, and says so.

  • It runs axe-core in a real browser on your machine.
  • It puts what it finds in order, worst first, with the fix for each.
  • It writes JSON for an agent and Markdown for a person.
See the repository

What it does

  • A real browser

    It loads the page in the Chrome already on your machine, or in Edge, with a new, empty profile each time, deleted afterwards. Your own profile, cookies and sign-ins are never opened.

  • Worst first

    It runs axe-core's rules on the page and orders what it finds by the harm to a person. Each finding names its rule, the WCAG success criterion where there is one, and the elements it hit.

  • For agents and people

    scan.json has a versioned schema and exit codes that mean something, for an agent or a script. report.md says the same in plain words, for a person.

  • Every page is a stranger

    A scanned page gets no downloads, no permissions and no pop-ups, and a public page cannot reach your own network through the scan. Its text is quoted as data, never run.

A11y Genie is in early development. Today it scans one page at a time; more is on the way.

From a scan of a test page in A11y Genie's own tests.

What it never claims

A11y Genie never tells you a site is done, or that it meets a standard. Automated rules find only some of the problems a person would. So every report says what it checked and what it found, and ends with What this scan cannot see: focus order, whether alternative text says what an image is for, captions, zoom, and whether someone using a screen reader can finish the page's main task.

A scan with no findings says how much it checked, and nothing more:

No problems found by these 90 rules on this page. Automated rules find only some problems; the checklist covers what they cannot see.

Quick start

npx a11y-genie scan <url>

You need Node 24 or newer and Chrome. With no Chrome, it says so and downloads Playwright's Chromium once, about 200 MB; --no-download refuses instead. It writes scan.json and report.md to a scans folder of your own, never into the folder you run it from, and exits 1 when it found something.

It isn't on npm yet. Until it is, build it from a clone.
